# GitHub 项目调研

核对日期：2026-11-26。目标：确认 `https://nav.peptide.ink/` 的程序来源，并寻找可继续开发的代码。

## 找到了原站同源项目

[tsxcw/mtab](https://github.com/tsxcw/mtab) 是参考站使用的 **mTab 书签导航**项目。

确认依据：

1. 原站公开前端包含 `mTab书签版权所有©`、`https://www.mtab.cc` 和其文档地址。
2. 原站使用 Vue、Element Plus、卡片组件、`/index/all` 公共配置与书签接口，和 mTab 仓库的结构及功能一致。
3. 参考站 HTML 声明版本为 `3.2.8`。仓库默认分支 `itushan` 含 ThinkPHP 后端及 `public/dist/` 编译前端；核对时没有 Vue `.vue` 源文件，也没有前端 `package.json`。

**结论：能找到同源公开仓库，适合研究或部署原版；仓库并没有提供当前参考站完整的可编辑 Vue 源码，不能把它等同于完整前端源码。**

## 本次实现选择

使用 Vue 3、TypeScript、Vite 单独实现可编辑前端，采用参考站公开的书签数据、壁纸和图标。没有把压缩后的线上脚本当成项目源码，也没有连接原站的登录或写入接口。

默认数据包括 5 个分类、252 条书签、24 个组件/文件夹和 7 个快捷入口。图标以页面实际渲染的结果校准，避免公共配置中的旧图标与页面不同。

桌面首页的首两排卡片在 1440×900 视口下按原站实测值还原：第一排起点为 `(167.5, 260)`、`(547.5, 260)`、`(927.5, 260)`，宽卡片为 `345×157 px`，加标题的总高度为 `177 px`；第二排从 `y=454` 开始。

移动端分类栏改为底部显示，修正参考站的侧栏遮挡。天气、热搜保留参考数据快照，个人功能使用本地存储；账号与云同步需要后续单独开发后端。
